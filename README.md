# Amazon-Clone-Webpage
A responsive Amazon Clone webpage built using HTML and CSS, featuring an Amazon-style navigation bar, search section, product categories, hover effects, and a full-width footer. Created as a front-end web development practice project.**
 A beginner-friendly **Amazon-inspired website clone** built using **HTML and CSS** as part of my web development learning journey.
 About This Project-

I created this project to understand how a real-world website can be designed and structured using **HTML and CSS**.

Instead of only learning HTML tags and CSS properties theoretically, I wanted to apply them to a practical project. I chose an Amazon-inspired e-commerce layout because it contains many important frontend concepts such as navigation bars, search boxes, product sections, images, buttons, hover effects, and footers.

The main purpose of this project is **learning and practice**, not creating a fully functional e-commerce website.

While building it, I learned how to break a large webpage into smaller sections and then build and style each section individually.

 Challenges & Learning-

While creating this project, I faced several layout and styling problems, such as incorrect class names, image paths, element alignment, spacing, footer width, and positioning.

For example, I learned that even a small mistake in a CSS class name can prevent the styling from being applied correctly.

Instead of just fixing these problems, I tried to understand **why they happened and how CSS works behind them**.
